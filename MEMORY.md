## App structure (two sides)

- `/` → workspace chooser · `/studio` → **Guest Studio** (client-facing) · `/admin` → **My Workspace** (internal)
- `src/studio/` = client-facing code; `src/admin/` = internal; `src/components/ui` + `src/lib` = shared.
- ESLint blocks `src/studio/**` from importing admin code (verified: probe import fails with `no-restricted-imports`).
- `ConfigBanner` (setup warnings) renders only in the My Workspace, never in the Studio.

## Standing requirements (from the user)

- **Client-facing:** the app is opened in front of guests — every screen must look professional. Guest View never shows cost, margin, P&L, master-rate hints, vendor names or internal remarks (render-level, not CSS-hidden).
- **Login-based, per-user workspaces:** every user's elements, packages, vendors, rates, options and quotes are fully separate (`owner_id = auth.uid()` RLS on every table, composite FKs so rows can't reference another user's data). After login the user chooses Guest Studio or their Workspace. Studio shows the user's own business name/logo from `profiles`.
- **Unit tests the same day** as each feature; a day isn't done until `npm test` passes.
- Every list is **server-side paginated**; LMS proxy and write RPCs are **rate limited**.
- **Optimised:** lazy routes, cached queries, column-limited selects, indexes.
- Packages are **never** linked to or filtered by function.
- SVG icons only (shared `Icon` component), no emoji.
- Never invent LMS field names, prices, costs or credentials.

- **Design system (28 Oct, v2):** rules in the project skill `.claude/skills/entertainment-presentation-ui/SKILL.md` — read it before any UI change. Palette: charcoal/midnight stage (`stage-*`, `.stage-bg`, swaying `StageLights`), **champagne gold accent `brand-*`** (every former `indigo-*` class was renamed to `brand-*`; gold fills carry dark text), ivory text on the stage (`text-ivory`; StudioLayout sets it, so white panels must set `text-slate-900`). - **Line endings:** Python `io.open(..., 'w')` on Windows writes CRLF — it silently turned 57 files CRLF (27 Oct) and broke exact-match patches. Use Node `.cjs` patch scripts (fs keeps LF) or the Write/Edit tools; if needed, normalise by replacing CRLF with LF in a Node one-liner.
